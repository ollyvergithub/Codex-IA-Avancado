# Mari Nutricionista

Site desenvolvido para apresentar os serviços de uma nutricionista e facilitar o contato de novos pacientes.

## Stack

- [React](https://react.dev/) para a interface
- [TypeScript](https://www.typescriptlang.org/) para tipagem estática
- [Vite](https://vite.dev/) para desenvolvimento e build
- [Tailwind CSS](https://tailwindcss.com/) para estilos
- [Framer Motion](https://motion.dev/) para animações
- [Lucide React](https://lucide.dev/) para ícones
- [React Router](https://reactrouter.com/) para navegação

## Instale as dependências do projeto

Antes de começar, tenha o Node.js `^20.19.0` ou `>=22.12.0` e o npm instalados. Na pasta do projeto, execute:

```bash
npm install
```

## Execute o projeto

Inicie o servidor local de desenvolvimento com:

```bash
npm run dev
```

Abra no navegador o endereço exibido no terminal.

Para gerar a versão de produção, execute:

```bash
npm run build
```

Para visualizar localmente a versão gerada, execute:

```bash
npm run preview
```
